# edusync
EduSync is a digital dashboard designed to improve communication, coordination, and engagement across educational institutions. It provides students, faculty, and campus staff with a centralized interface 

📢 Receive Announcements – Stay updated with important campus-wide messages.

📅 View Upcoming Events – Track academic schedules, club activities, and campus events.

👥 Engage with Groups & Clubs – Discover and participate in student communities and interest-based groups.
